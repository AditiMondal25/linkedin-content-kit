# The 7-File LinkedIn Content Kit

A plain-text system that makes AI write LinkedIn posts that sound like you instead of
like everyone else. No app, no subscription — seven text files you keep in a folder
and give to your AI tool before it writes anything.

Built by [Aditi Mondal](https://www.linkedin.com/in/aditi-m-285b631b1/), a virtual
assistant who runs her whole LinkedIn content system on these files.

## Why this works

AI doesn't underperform because it's bad at writing. It underperforms because it
knows nothing about you. These seven files are its onboarding: how you sound, who
you write for, the only numbers it may use, your real stories, the words it must
never say, and every correction you've ever given it.

After setup, output stops being "10 tips for synergy" and starts sounding like your
business.

## The 7 files

| File | What it tells the AI |
|---|---|
| `CLAUDE.md` | Read this first: your goal, the workflow, the scorecard every draft must pass |
| `Voice-DNA.md` | How you write — tone, patterns, sentence style, what to avoid |
| `ICP-Doc.md` | Who you write for — their role, frustrations, what they want |
| `Proof-Points.md` | The only facts and numbers the AI may use. Nothing else exists |
| `Story-Bank.md` | Your real stories, each marked `public`, `ask me first`, or `private` |
| `AI-Banned-Words.md` | Words and phrases the AI must never use (ready to use as-is) |
| `Corrections-Log.md` | Every fix you give the AI, dated. It reads this before every draft |

## How to use it

**With Claude (Projects):**
1. Create a Project, upload the 7 filled-in files.
2. Paste `CLAUDE.md` into the project instructions.
3. Ask for a post. The AI reads the kit before writing.

**With ChatGPT or any other tool:**
1. Start a chat by pasting `CLAUDE.md` and the other 6 files.
2. Ask for a post in the same chat, so the context persists.

**The rules that make it work:**
- Fill every `[bracket]` with a real answer. If you don't know, leave the bracket —
  a gap the AI must ask about beats a guess it invents.
- Only facts in `Proof-Points.md` may appear in posts. Add a fact there first,
  then use it.
- Every time you correct a draft, add the correction as a dated line to
  `Corrections-Log.md` before doing anything else. The kit gets smarter every week.
- Mark stories honestly. `private` means the AI never touches it.

## Start small

Don't fill all seven files in one sitting. Start with `Voice-DNA.md` and
`AI-Banned-Words.md` tonight — those two alone change the output. Add the rest
over a week.
